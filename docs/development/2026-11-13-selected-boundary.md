# Explicit hand-drawn boundary sampling

## Design choice
The user needs hand-drawn lines to partition regions while preserving the original artwork and editable layers. Sampling the final colored composite would quietly turn unrelated colors/details into boundaries. Automatically tagging all finishing strokes would have the same problem. This implementation instead requires an explicit selected finishing layer, displayed by name; changing the active drawing layer does not silently change it. The choice is session-only and clears on reopening/new document.

## Bounded behavior
The selected layer is rendered alone on transparent paper using its actual strokes, pressure, opacity and erasing. Only alpha coverage >=128/255 becomes a temporary sampling obstacle. RGB is irrelevant, and original events/color/opacity are never changed. Semi-transparent edges below the threshold, dry-brush holes, and erased openings remain open. No automatic dilation, sealing or upsampling is applied. The current preview must be inspected before accepting.

Fill remains limited to the original lineart's white/transparent lower-color domain, augmented by previously explicit gap barriers. Cleared original-ink/hollow regions are not enabled by this mode: stop selected-boundary sampling to use the existing hollow-region path. Other finishing layers and existing colors are never sampled. A missing or hidden chosen layer rejects the operation rather than silently reverting to another source.

All candidate creation is worker-side, cancellable and bounded. Full strict mixed-stack validation, existing original-white domain validation, source resources, layer semantics, timeline rebase, preview/cancel, Undo and project save/reopen remain in effect. No claim that image dimensions imply new original detail; no private artwork is submitted with code. This adds an editing capability, not a finished drawing or artist-quality result.

## Validation
Reviewed Release build: 105/105 tests passed (-j4, 29.26 s wall time), including actual Qt/QML 17.89 s. QML exercises real pointer closed-loop drawing, explicit boundary selection, inside-only color preview, cancellation, accept/Undo/redo, exact save/reopen and selection reset, and hidden-boundary refusal. Core B39 also covers unrelated color-layer exclusion, real erasing opening a boundary, below-threshold transparency, original data preservation and cancellation/budget rejection. A separate synthetic native 1725×2625 closed-frame core experiment passed without resampling, 0.082 s for core fill/apply; this is not a GUI or complex-artwork performance claim. Review corrected concurrent barrier-vector accounting in render/fill budgets. The initial desktop build stopped on a misleading-indentation warning; formatting was corrected and the entire suite rerun. Windows/physical pen remain untested. Conservative incremental allocation accounting is not a total process-RSS guarantee; budget refusal must not silently downsample.
