# Desktop authored solid → independent pixel layer (WIP)

This entry is enabled only with `DRAWBORAD_QT_SOLID_MASK_CACHE=ON`. It serves manual silhouette/control-point work, not automatic reconstruction of a reference image. No reference pixels are used. The default build does not expose the new entry as available.

For a closed two-span six-point draft, the user explicitly chooses the independent-pixel-layer preview. A private candidate Document is rendered through the real merged-document pipeline, rather than drawing a misleading overlay on top. The existing async stop/revision/document/generation checks reject cancelled or stale results. The user may return to the unchanged draft, cancel, or accept one atomic new layer. Saving a pending draft remains blocked by the existing protection.

Acceptance names/selects the new locked pixel layer and explains that its control points cannot be edited afterwards. Original curves, nodes and resources are not replaced. Existing selected curves use their own stored color/opacity, not the last new-draft QColor. The accepted layer uses the previously verified portable cropped-Normal representation; it is not a new vector format or MyPaint-generated artwork.

Limits remain RGB8 without ICC, original pixel dimensions, existing16MiB single-layer raw budget, and an explicit refusal rather than hidden resampling. A large canvas does not guarantee every full-page shape fits one layer. The application is not claimed to provide linear-light color, CMYK/print accuracy, Windows/tablet qualification or finished artwork.
