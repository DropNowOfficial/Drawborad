## 2. 工作区与视觉结构

欢迎页：直接提供新建、导入图像、打开工程、本地模型包与最近工程。没有强制登录、联网模板市场、营销弹窗。

新建面板：宽高/单位/PPI/比例、方向、RGB/CMYK、8/16-bit、ICC、透明背景/纸色、预估资源。预设与自由输入并列；错误就地提示。

Review 工作区：原图与候选对象边界、对象树、置信提示、加减选、蒙版修边、确认局部/全部接受。原图参考可见但不属于重绘完成层。

创作区：中央单一稳定画布；左侧少量高频工具；右侧对象/阶段树和可收起属性；顶部只呈现当前工具参数；底部任务状态。默认不占用整条时间轴，打开回放工作区后再出现。

两种密度：简洁模式像工作台，只保留高频操作；专业模式显示 ICC、CMYK 通道、蒙版、变换、混合和历史。两者切换不能重建文档、丢失选择或改变图像。

导出页：格式/尺寸/色彩/透明/位深/路径与兼容性预检；转换前后对比放在明确比较模式。PSD/PNG 的能力不同，在这里解释，不靠导出后发现错误。

## 3. 设计令牌与行为

- 间距使用 4/8 DIP 基准，光学对齐优先于机械居中；常用文字 13–14 DIP 起步，辅助文字通常不小于 11 DIP，可随系统文本设置放大。不是把网页 8px 标签直接搬到软件。
- 标题、分组、属性和任务状态通过字重/对比/距离共同分层；正文保留足够行距，中文与英文分别检查。中英切换避免固定宽度截断，不翻译用户命名。
- 深色画布外框为中性灰，浅色界面无明显黄偏；画布颜色与 UI 主题独立。颜色比较、CMYK 数值和取色区使用实心背景，禁止毛玻璃改变图像判断。
- 小范围材质和柔和阴影用于浮层层级；禁止全屏模糊、持续漂浮背景、无目的弹跳。低功耗/减少透明度模式可完全禁用材质而不损害功能。
- 按下立即给反馈；拖动 1:1 跟手。面板/菜单转场可从当前状态中断与反向，不阻止输入。非输入关键路径的过渡以约 120–220ms 为待验证设计值；不能在画笔路径上增加延迟。
- 错误说明包含发生了什么、已保留什么和可执行的恢复动作。长任务提供真实进度、取消和结果版本；进度不能固定时间走满。
- Ctrl+S/Z、Alt、方向键、Esc、空格画布平移等有明确冲突规则；焦点可见，控件可键盘访问。窗口维持 Windows Snap、系统菜单和本机文件对话框。
- 工具提供提示、快捷键和禁用原因。减少运动/高对比/系统文本放大均有对应状态。图标/字体使用系统或已审核可再分发资产，不打包 Apple 字体。

## 4. 三项质量同时验收

Q-Fidelity：输入、重建结果分别经过同一 ICC 显示/比较链，图像不通过引用输入像素或在终点换图完成。评估全图和关键区域；文字/Logo、轮廓、透明边缘单独验收。禁止只用缩略图或全局平均分掩盖局部失真。

Q-Layers：对象可选择、隐藏、移动和编辑蒙版；非选中对象不被错误改写。阶段子层有实际内容，不把原图重复放进所有层。被遮挡区域默认不推测；原有图层导入与 AI 重建图层的来源可区分。

Q-Process：从空白到完成的每一个变化都有事件。不能全幅随机短线、无意义起稿、上色后偷换照片、最后一秒补贴整张残差图。局部顺序解释该区结构；支持暂停/返回/单步。人工自然度评审与图像误差评分分别记录。

量化起始目标（非实测）：在冻结的代表性 Fidelity 测试集上，规范化 RGB 合成 SSIM >= 0.98，可比较色域内平均 DeltaE00 <= 2、P95 <= 5；透明素材 Alpha MAE <= 2/255，并分别在黑/白/中灰底检查边缘。CMYK 在固定 ICC/意图下比较受控软打样，同时记录原 CMYK 通道偏差和油墨信息。不是将转换导致的色域限制解释为笔迹算法错误，也不将这些数字承诺给所有任意输入。

上述阈值必须与关键区域人工检查同时通过。风格模式使用自己的参考意图，不借用 Fidelity 的阈值做虚假通过。自动分层失败时能够修正，不声称任意图片无需干预。任何一项未通过，整项功能不算通过。

## 5. 测试矩阵与停止条件

所有测试记录 Pass / Fail / Blocked；未执行不能填 Pass。性能计数来自实际运行，不用截图或推算替代。

### 基准环境

Windows 11 x64；Core Ultra 9 185H；32 GB RAM；RTX 4070 Laptop 8 GB。记录 OS build、驱动、电源模式、显卡选择、窗口大小/DPI、模型/算法/配置哈希、CPU/GPU 峰值内存、输入类别与色彩配置。渲染用显卡与 CUDA device 对应关系必须核验。

### 功能与正确性

- 自定义输入类别不少于产品、人像、头发/毛发、插画、文字海报、UI 截图、线稿、透明物和复杂背景；不少于 80 份有使用权的固定样本，加 200 个程序化格式/边缘样本。训练/调参与最终验收集分开。实际数量写入报告，未准备好则 Blocked。
- RGB/CMYK 8/16-bit、ICC 缺失/损坏、Display P3/Adobe RGB、自定义 CMYK profile、透明边缘、尺寸和 PPI 换算逐项检查。强制 CMYK 四通道读取，不以 RGB 预览可见代替支持。
- PSD 往返包括组、中文名、蒙版、透明度、每种启用的混合模式；独立解析器和 Photoshop 实际打开。原生工程重开、PNG/TIFF 对应合成一致；JPEG/WebP 等有损格式使用误差标准而不是文件哈希。
- PSB 输入的正常与超资源样本；PSB 输出应不可选择；PSD 超限必须清晰拒绝或给显式替代方案。
- 锁层、显隐、复制/删除/顺序、蒙版修补、分层确认、色彩转换、笔压力度、撤销重做与版本恢复。10,000 个可重放随机编辑命令验证事务一致性。
- 同工程锁定 CPU 渲染器重复导出规范化像素哈希一致；时间轴缓存命中、从白纸执行、往返定位一致。GPU 路线另列容差，不冒称跨驱动逐像素一致。

### 性能目标

基准一：4096×4096、RGBA 8-bit、16 个可见层、100 万条已索引笔迹，热缓存交互 P95 帧耗时 <= 16.7ms 为期望，<= 33ms 为首版通过线。

基准二：同尺寸 64 个可见层，包括混合/蒙版版本，P95 <= 33ms 为通过线；CMYK/16-bit 单列报告，不借用 RGBA 成绩。128 层为压力档，允许缓存回收与更长任务，但不得卡死、崩溃或丢工程。

8K 可后台处理与导出，必须保留分辨率；不将其声明为 60FPS 保证。实时笔刷、面板、任务取消反馈不得等推理结束；常见按钮反馈目标 <= 100ms。热缓存时间轴定位目标 <= 1s，冷恢复单独记录。模型加载和重绘任务时间分开，不伪造一个总快数值。

内存与显存目标依主规格软预算，记录峰值和回收效果；运行 8 小时后不能有随任务数量持续增长的未释放资源。长时间功耗/温度导致的降速记录在报告，不通过未测假定规避。

### 稳定性、安装与恶意输入

- 24 小时队列压力、8 小时交互稳定性；连续取消/重启任务；模拟 worker crash、GPU device lost、磁盘不足、目录只读、断电恢复、损坏 journal、休眠后恢复。
- 离线新装 Windows 环境，阻断应用网络仍能安装、启动、加载模型和完成导出；模型包损坏/篡改/不兼容/路径穿越拒绝，未知模型不执行附带代码。
- 文件名中文/emoji、长路径、重复名、共享文件占用、无管理员启动、安装/卸载、用户数据保留、portable 路径变更。
- 编解码器、项目包、模型 manifest 进行有时间和资源上限的模糊测试，发现崩溃必须归档为回归样本。构建机测试结果不能冒称用户真机结果。

### 视觉、动效和可访问性

Windows DPI 100/125/150/200/250%；1366×768 到 4K、多显示器切换；中英双语、系统文本放大；没有截断、不可达按钮和覆盖画布的重要对话。鼠标与数位笔分测。屏幕逐帧检查转场可中断性，长任务期间验证仍可拖窗和取消。界面普通文本对比度目标至少 4.5:1，关键非文本边界至少 3:1，高对比模式有明确状态。

发布停止条件是：零已知阻断缺陷、零已知数据丢失缺陷、以上核心检查通过、未通过功能被禁用并明确列出、关键流程人工复核完成。获奖级是设计追求，不是“没有任何提升空间”的不可验证保证。
